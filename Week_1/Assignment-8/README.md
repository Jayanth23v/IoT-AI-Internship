# Assignment 8 – Hardware Setup Documentation

This assignment documents the hardware connections and practical experiments performed during Week 1 of the IoT with AI internship.

## Simulation Platform

Tinkercad Circuits was used to design and test the Arduino circuits because physical hardware components were not available.

## Components Used

1. Arduino Uno R3
2. Breadboard
3. LEDs – Red, Yellow and Green
4. Push button
5. 220Ω resistors
6. TMP36 temperature sensor
7. Jumper wires

## Experiments Documented

### 1. Three-LED Blinking Circuit
Three LEDs were connected to Arduino Uno and controlled sequentially using digital output pins.

### 2. Push Button Controlled LED
A push button was connected to digital pin 2 and used to control an LED connected to digital pin 13.

### 3. Temperature Sensor Interfacing
A TMP36 temperature sensor was connected to analog pin A0. Temperature readings were displayed using the Serial Monitor.

## Testing and Verification

The circuits were designed and tested using Tinkercad simulation.

The following operations were checked:
- Sequential LED operation.
- Push button input detection.
- LED ON/OFF control.
- Temperature sensor readings.
- Serial Monitor output.

## Conclusion

The practical activities provided an understanding of Arduino connections, electronic components, sensor interfacing and circuit simulation. Tinkercad helped test the experiments without physical hardware.
