# Assignment 3 – IoT System Architecture

This assignment explains the architecture of an Internet of Things (IoT) system and the communication between its different layers.

## Main Layers of IoT Architecture

1. Perception Layer – Collects information using sensors and physical devices.
2. Network Layer – Transfers collected data through communication technologies.
3. Processing Layer – Processes, stores and analyses the collected data.
4. Application Layer – Provides services and information to end users.

## Working Principle

Sensors collect data from the environment. The network layer transfers the data to the processing layer, where it is analysed. The application layer displays useful information to users.

Actuators can receive control commands to perform physical actions.
