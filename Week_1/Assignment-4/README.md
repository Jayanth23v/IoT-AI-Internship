# Assignment 4 – Analog and Digital Signals

This assignment explains analog and digital signals and their use in electronics and Arduino-based systems.

## 1. Analog Signals

An analog signal is a continuous signal that can have different values over a range.

Examples:
- Temperature sensor output
- Microphone signals
- Light intensity measurements

Arduino uses analogRead() to read analog input values.

## 2. Digital Signals

A digital signal has discrete values, commonly represented by binary states 0 and 1.

Examples:
- Push button input
- LED ON/OFF control
- Digital switching circuits

Arduino uses digitalRead() to read digital inputs and digitalWrite() to control digital outputs.
