# Assignment 2 – Common IoT Sensors

This assignment explains commonly used sensors in IoT projects, their working principles and real-world applications.

## Sensors Covered
1. Temperature Sensor – TMP36 / LM35
2. Humidity Sensor – DHT11 / DHT22
3. Ultrasonic Sensor – HC-SR04
4. PIR Motion Sensor – HC-SR501
5. Light Sensor – LDR
6. Gas Sensor – MQ-2
7. Soil Moisture Sensor
8. Sound Sensor – KY-038
9. Pressure Sensor – BMP280
10. Accelerometer – MPU6050
