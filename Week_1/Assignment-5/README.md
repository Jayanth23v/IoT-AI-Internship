# Assignment 5 – LED Blinking Circuit Using Arduino

This assignment demonstrates how to control LEDs using an Arduino Uno and a simple electronic circuit.

## Components Used
1. Arduino Uno R3
2. Red LED
3. Yellow LED
4. Green LED
5. 220Ω resistors
6. Breadboard
7. Jumper wires

## Pin Connections
- Red LED – Digital Pin 13
- Yellow LED – Digital Pin 12
- Green LED – Digital Pin 8

Each LED is connected through an individual 220Ω resistor.

## Working Principle

The Arduino controls three LEDs sequentially using digital output pins.

1. Red LED glows for 2 seconds.
2. Yellow LED glows for 1 second.
3. Green LED glows for 2 seconds.
4. The sequence repeats continuously.
